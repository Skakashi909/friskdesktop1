# Ruflo in Frisk

Optional settings in Frisk memory/preferences:
- `ruflo_routing_enabled`: true (default) — route complex tasks through Ruflo when installed.
- `ruflo_learning_enabled`: true (default) — store compact successful task summaries in Ruflo's local memory.

Install on Windows with `scripts\install_ruflo.ps1` (it installs Ruflo globally). Frisk runtime does not auto-download Ruflo or npm packages. No API key is required for trying Ruflo, and the project is MIT-licensed.
